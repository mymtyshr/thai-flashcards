# タイ語マイフレーズ

旅行用タイ語フレーズを、音声つきフラッシュカードで覚える個人用PWA。サーバー・APIキー・月額費用は不要。

## ファイル
index.html / style.css / app.js / sw.js / manifest.webmanifest / icon.svg / icon-192.png / icon-512.png / apple-touch-icon.png
（すべて同じフォルダに置く）

## 無料で公開する（GitHub Pages）
1. github.com でアカウントを作り、新しいリポジトリを作る（例: thai-phrases、Public）。
2. 「Add file → Upload files」で、このフォルダの中身を**フォルダごとではなく中身のファイルすべて**をアップロードして Commit。
3. Settings → Pages → Source を「Deploy from a branch」、Branch を「main / (root)」にして Save。
4. 1〜2分後に https://（ユーザー名）.github.io/thai-phrases/ で開ける。

## iPhoneで使う
1. Safariで上のURLを開く（Chromeではなく**Safari**）。
2. 共有ボタン → 「ホーム画面に追加」。
3. ホーム画面のアイコンから起動。一度開けば、オフラインでも画面は動く。

## 音声が出ないとき
- 消音スイッチ（サイレントモード）をオフ、音量を上げる。
- 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → タイ語 で音声（Kanya など）をダウンロード。
- アプリの「設定」画面のテスト再生と、使用中の音声表示を確認。
- 「タイ語の音声が見つかりません」と出る場合は、端末にタイ語音声が未導入。他言語の音声では読み上げない仕様。

## フレーズをすべて削除する
設定画面の「フレーズをすべて削除」で、登録済みのフレーズと学習記録を、すべて消せる（2回確認する。元に戻せないので、先に「JSONとして書き出す」を勧める）。話し手・再生速度などの設定は残る。空になっても、「まとめて追加」や、設定の「初期の15フレーズに戻す」で入れ直せる。クラウド連携中でも、空の状態はクラウドに送らない（クラウドの控えは、そのまま残る）。

## 話し手（男性／女性）
初めて開いたとき（保存データがないとき）に、男性の言い方（ครับ）か女性の言い方（ค่ะ・คะ）を選ぶ。初期の15フレーズが、選んだ言い方で入る。設定画面の「話し手」で後から変えられるが、すでに入っているフレーズの語尾は変わらない（AIへの依頼文は、新しい話し手に従う）。「初期の15フレーズに戻す」は、いまの話し手の初期フレーズに戻す。
女性用の初期フレーズは、男性用の語尾を、疑問文は คะ、それ以外は ค่ะ に替えて作っている。この語尾の替え方は、タイ語話者の確認を受けていない。

## フレーズをまとめて追加する
### AIに作ってもらう（手入力しない方法）
1. ホーム画面または一覧画面の「まとめて追加（AIで作る）」を開く
2. 「どんな場面のフレーズ？」に場面（例：美容院）を入れ、件数と話し手（男性 ครับ／女性 ค่ะ）を選び、「AIに送る文章をコピー」を押す
3. ChatGPTやClaudeなどのチャットに貼り付ける（依頼文には、登録済みのフレーズ［覚えたもの・まだのもの］が参考として入る。各50件まで。同じ内容のフレーズを避け、覚えたものと同じくらいの難しさにするよう頼んでいる）
4. AIが出したコードブロックの中身をコピーし、「②AIの答えを貼り付ける」に貼って「追加する」を押す

番号・「-」・コードブロックの線・表の枠線が付いていても読み取る。登録済みのフレーズは追加されない。書式が合わない行だけが欄に残るので、直してやり直せる。AIの答えのタイ語・発音記号は間違うことがあるので、気になる語は確認すること。

### 手で書く場合
「まとめて追加」に、1行1フレーズで貼り付ける。
`日本語｜タイ語｜カタカナ｜カテゴリー｜単語分解`（カタカナ以降は省略可。区切りは ｜ か | かタブ）
タイ文字のない行・空欄の行・登録済みのタイ語は追加されず、理由が表示される。既存データは消えない。

## 単語ごとの分解
カードをめくると、単語ごとの枠に「タイ語・発音記号（IPA）・和訳」が並ぶ（声調記号は表示しない）。設定画面の「単語の発音表示」で、カタカナ表示や両方表示にも切り替えられる（単語分解のあるフレーズは、全文のタイ語と全文のカタカナは出さない）。分解がないフレーズは、従来どおり全文とカタカナを出す。一覧画面にも分解が表示される。カード裏面の単語の枠をタップすると、その単語だけタイ語で読み上げる（もう一度タップで停止）。
追加・編集画面の「単語の分解」に、1行1語で `タイ語＝和訳＝発音記号＝カタカナ` と書く（発音記号とカタカナは省略可）。
まとめて追加では5列目に `タイ語＝和訳＝発音記号；タイ語＝和訳＝発音記号` とつなぐ。
初期の15フレーズには分解・発音記号・カタカナが入っている。この更新より前から使っている場合も、手を加えていない初期フレーズには自動で補われる。自分で編集した分解は上書きしない。

## 学習状況をAIに渡す
設定画面の「学習状況をコピー」を押し、Claudeのチャットに貼ると、次に学ぶフレーズを提案してもらえる。
見た回数・「まだ」の回数・最終日・覚えた日が、カードの「覚えた／まだ」を押すたびに記録される（この更新より前の記録は回数が0から始まる）。
提案されたフレーズは「まとめて追加」にそのまま貼れる形式で出る。

## クラウドにバックアップする（Googleスプレッドシート）
学習記録を、Googleスプレッドシートに自動でバックアップできる。使わない人には何も送信されない（初期は無効）。送信先は `script.google.com` のURLだけ。
**スプレッドシートは1つでよい。** 作る人（Googleアカウントを持つ人）が1回だけ準備し、使う人ごとに「名前」を決めて、同じURLと合言葉を入れる。名前ごとに別のシートができるので、記録は混ざらない。**使うだけの人は、Googleアカウントがなくてよい。**
- 作った人は、スプレッドシートで全員の進み具合を見られる（`サマリ` と `進捗_名前` のシート）
- 使うだけの人は、スプレッドシートを開けない（開けるようにするには、作った人が共有する）
- 作った人は、使う人の記録を見られる。見せてよい相手とだけ共有すること

### 準備（作る人が、最初の1回だけ。10分ほど）
1. [Googleスプレッドシート](https://sheets.google.com) で、新しいスプレッドシートを作る（名前は自由）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードを全部消し、このリポジトリの `cloud/Code.gs` の中身を貼り付ける
4. 先頭近くの `const SECRET = '…';` の**この1行だけ**を、自分たちだけの合言葉に書き換える（他人に教えない）。`'` の引用符は消さない・全角にしない（`const SECRET = 'abc123xyz';` の形）。「置換」機能は使わない。保存する
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、権限の確認が出たら進める（「このアプリは確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動」。自分のスプレッドシートを操作する許可）
6. 出てきた「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピーする
7. 使う人に、**URLと合言葉**を、LINEなどで直接伝える（公開の場に書かない）

### 招待リンクで渡す（URLと合言葉を打たなくてよい）
1. 作る人が、自分の設定画面にURL・合言葉を入れ、「招待リンクをコピー」を押す
2. そのリンクを、LINEなどで相手に**直接**送る（URLと合言葉が入っているので、記録を預けてよい人だけに）。名前はリンクに入らない
3. 相手の端末での流れ
   - 相手が、リンクをタップして開く（iPhoneでは**Safari**で開く）→ 話し手を選ぶ → 設定画面に、URLと合言葉が入った状態で開く
   - その状態で、Safariの共有ボタンから「ホーム画面に追加」する。ホーム画面のアプリで開いて、設定画面のクラウドの欄が空なら、次の「貼り付ける方法」を使う
   - **名前を入れて**、「この端末のデータを送って始める」を押す
4. 貼り付ける方法：リンクをコピーして、**ホーム画面のアプリ**の設定画面の「招待リンクを受け取った人は、ここに貼り付け」に貼り、「招待を読み込む」を押す。LINEの文章ごと貼ってよい
- iPhoneでは、Safariとホーム画面のアプリで、記録の保存場所が別になる。そのため、Safariで開いただけでは、ホーム画面のアプリには設定が入らないことがある（手順3の流れで入るかは、端末で確かめること。入らなければ、4で確実に入る）
- リンクの `#invite=…` の部分は、サーバーには送られない。ただし、リンクを知っている人は、そのスプレッドシートに書き込める

### アプリ側（使う人それぞれ）
1. 設定画面の「クラウドにバックアップ」に、URL・合言葉・**あなたの名前**を入れる。名前は、使う人ごとに**別の名前**にする（同じ名前だと、お互いの記録を上書きする）
2. 初めて使う端末は「この端末のデータを送って始める」。機種変更や、データが消えたあとは「クラウドから復元して始める」（同じ名前を入れる）
3. 始めると、カードで「覚えた／まだ」を押すなど記録が変わるたびに、数秒後に自動で送る（圏外のときは、つながったときに送る）。「今すぐ送る」もある

### 仕組みと注意
- スプレッドシートに、人ごとに `backup_名前`（復元用。消さない）、`backup_prev_名前`（前の日までの分を1世代だけ保管）、`進捗_名前`（フレーズごとの覚えた・見た回数。見るだけ）のシートができる。全員の `サマリ` も1枚できる。名前は20文字以内で、`[ ] * ? : / \` は使えない
- 「始める」前の端末は、クラウドを上書きしない。上書きするときは確認が出る
- 「初期の15フレーズに戻す」は、連携中だとクラウドも初期状態で上書きする
- 1人は1台の端末で使う想定。同じ名前を複数の端末で同時に使うと、最後に送った端末の内容になる
- URLと合言葉を知っている人は、そのスプレッドシートに書き込める。他人に見せないこと。URL・合言葉・名前は、書き出しファイルやAI用の文章には入らない
- スクリプトの中身を直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」で更新する

## AIに追加してもらう（自動）
「まとめて追加」で、**何個ほしいか**（1〜30）を入れて「AIに追加してもらう（自動）」を押すと、AIが、いまの学習状況（覚えたフレーズ・苦手なフレーズ・登録済みのフレーズ）を踏まえて、新しいフレーズを選ぶ。場面を入れなければ「おまかせ」になる。登録済みのフレーズは追加されない。
「追加のしかた」を選べる。
- **すぐ追加**（初期設定）：その数だけ、すぐ追加する。追加したフレーズには「**AI・未確認**」の印が付き、一覧は未確認だけの表示になる。一覧やカードで聞いて確認し、「確認した」を押すと印が消える（間違いが見つかったら、編集か削除をする）
- **確認してから**：提案の一覧が出る。▶で音声を聞き、意味を確認して、選んだものだけを追加する

AIが作ったタイ語は、綴り・声調・和訳が間違うことがある。特に「すぐ追加」では、確認するまで、印を目安に、気をつけて覚えること。

### 準備（クラウドバックアップを作った人が、1回だけ）
この機能は、クラウドバックアップのスクリプトを通してAIを呼ぶ。先に「クラウドにバックアップする」を済ませておく。
1. [Anthropic Console](https://console.anthropic.com/) でアカウントを作り、「API keys」でAPIキーを作る。利用額の上限（Spend limit）も、ここで決めておく
2. スクリプトを最新の `cloud/Code.gs` に貼り直す（`SECRET` の1行は、自分の合言葉のまま）
3. Apps Script の左のメニューの歯車（プロジェクトの設定）→「スクリプト プロパティ」→ プロパティを追加：名前 `ANTHROPIC_API_KEY`、値 作ったAPIキー
4. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」

### 仕組みと注意
- APIキーは、スクリプトのプロパティにだけ入れる。アプリ・リポジトリ・書き出しファイルには入らない。アプリが通信するのは、これまでどおり `script.google.com` だけ
- 提案を押すと、依頼文（場面・登録済みフレーズの日本語とタイ語・苦手なフレーズと「まだ」の回数）が、スクリプトからAnthropicのAPIへ送られる。フレーズ以外の個人情報は送らない
- 呼ぶたびにAPIの利用料金がかかる。**1日30回まで**で止まる（`Code.gs` の `SUGGEST_MAX_PER_DAY`）。URLと合言葉を知っている人は、あなたのAPIキーを使って提案を呼べるので、他人に教えないこと
- 使うモデルは `Code.gs` の `MODEL`。変えたら、新バージョンでデプロイし直す
- この機能を使わない人は、何も設定しなくてよい（「AIに送る文章をコピー（手動）」は、これまでどおり使える）

## Claude Artifact版（claude.ai の中で動かす）
同じアプリを、claude.ai の Artifact として動かせる。ふつうのブラウザ版（GitHub Pages）とは**別の場所**で動き、記録も別になる。
- 学習記録は、**Claudeアカウントごとに**、Claudeの `db` に保存される（`data/users/<id>/`。本人だけが読める。ほかの人・作った人にも見えない）。書式は、ブラウザ版と同じ（`thai-my-phrases.v1` の中身）。1つの文書は256KiBまでなので、約4万文字ごとに分けて保存する
- AIへの依頼は、Apps Script・APIキーなしで、Claudeの `sample` 機能で行う。使う人自身のClaudeの利用枠が使われ、初回に許可の確認が出る
- ファイルの書き出しは `downloads` 機能で行う。確認は、`confirm()` ではなく、ページ内の確認画面を使う（Artifactでは `confirm()` が常に「いいえ」になるため）
- 使えないもの：ホーム画面に追加するアプリ、圏外での起動（claude.aiを開く通信が要る）、Googleスプレッドシートへのバックアップ・招待リンク（Artifact版では、設定画面に出ない）
- 使う人は、claude.aiにログインしている必要がある。記録を保存するには、作った人が共有メニューで「コントリビューター」以上にする（閲覧のみだと保存できない）

### ブラウザ版から記録を移す
1. ブラウザ版の設定 →「JSONをクリップボードにコピー」
2. Artifact版を開き、最初の画面で話し手を選ぶ
3. Artifact版の設定 →「貼り付けて復元」に貼り、「貼り付けた内容で復元」→ OK

### 作り直して公開する（開発者向け）
`node artifact/build.mjs 出力先.html` で、`app.js`・`style.css`・`artifact/host.js` を1枚のHTMLにまとめる。これを、`db`・`user`・`sample`・`downloads` の機能を宣言して、Artifactとして公開する。ブラウザ版とArtifact版の違いは、`window.thaiHost` がある場合だけ働く、`app.js` の差し替え口に限る。

## 注意
- 学習データはブラウザ内（localStorage）に保存。Safariのサイトデータを消すと失われるので、設定画面から書き出しておく。
- 合成音声なので、声調や自然さはネイティブ音声に劣る。気になる語はForvoやGoogle翻訳の音声で確認する。
- 音声を別サービスに替える場合は app.js の speak() だけを差し替える。

## 更新の反映
つながっているときは常に最新版を表示し、圏外や通信が遅いとき（4秒超）だけ端末のキャッシュで起動する。新しい版が入ると自動で一度だけ読み込み直す。設定画面の最下部に、端末に入っているバージョン（例：`thai-phrases-v10`）が出る。
