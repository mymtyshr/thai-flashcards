# タイ語マイフレーズ

旅行用タイ語フレーズを、音声つきフラッシュカードで覚える個人用PWA。サーバー・APIキー・月額費用は不要。

## ファイル
index.html / style.css / app.js / sw.js / manifest.webmanifest / icon.svg / icon-192.png / icon-512.png / apple-touch-icon.png
（すべて同じフォルダに置く）

## 無料で公開する（GitHub Pages）
1. github.com でアカウントを作り、新しいリポジトリを作る（例: thai-phrases、Public）。
2. 「Add file → Upload files」で、このフォルダの中身を**フォルダごとではなく中身のファイルすべて**をアップロードして Commit。
3. Settings → Pages → Source を「Deploy from a branch」、Branch を「main / (root)」にして Save。
4. 1〜2分後に https://（ユーザー名）.github.io/thai-phrases/ で開ける。

## iPhoneで使う
1. Safariで上のURLを開く（Chromeではなく**Safari**）。
2. 共有ボタン → 「ホーム画面に追加」。
3. ホーム画面のアイコンから起動。一度開けば、オフラインでも画面は動く。

## 音声が出ないとき
- 消音スイッチ（サイレントモード）をオフ、音量を上げる。
- 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → タイ語 で音声（Kanya など）をダウンロード。
- アプリの「設定」画面のテスト再生と、使用中の音声表示を確認。
- 「タイ語の音声が見つかりません」と出る場合は、端末にタイ語音声が未導入。他言語の音声では読み上げない仕様。

## フレーズをまとめて追加する
一覧画面の「まとめて追加」に、1行1フレーズで貼り付ける。
`日本語｜タイ語｜カタカナ｜カテゴリー｜単語分解`（カタカナ以降は省略可。区切りは ｜ か | かタブ）
タイ文字のない行・空欄の行・登録済みのタイ語は追加されず、理由が表示される。既存データは消えない。

## 単語ごとの分解
カードをめくると、単語ごとの枠に「タイ語・発音記号（IPA）・和訳」が並ぶ（声調記号は表示しない）。設定画面の「単語の発音表示」で、カタカナ表示や両方表示にも切り替えられる（単語分解のあるフレーズは、全文のタイ語と全文のカタカナは出さない）。分解がないフレーズは、従来どおり全文とカタカナを出す。一覧画面にも分解が表示される。カード裏面の単語の枠をタップすると、その単語だけタイ語で読み上げる（もう一度タップで停止）。
追加・編集画面の「単語の分解」に、1行1語で `タイ語＝和訳＝発音記号＝カタカナ` と書く（発音記号とカタカナは省略可）。
まとめて追加では5列目に `タイ語＝和訳＝発音記号；タイ語＝和訳＝発音記号` とつなぐ。
初期の15フレーズには分解・発音記号・カタカナが入っている。この更新より前から使っている場合も、手を加えていない初期フレーズには自動で補われる。自分で編集した分解は上書きしない。

## 学習状況をAIに渡す
設定画面の「学習状況をコピー」を押し、Claudeのチャットに貼ると、次に学ぶフレーズを提案してもらえる。
見た回数・「まだ」の回数・最終日・覚えた日が、カードの「覚えた／まだ」を押すたびに記録される（この更新より前の記録は回数が0から始まる）。
提案されたフレーズは「まとめて追加」にそのまま貼れる形式で出る。

## 注意
- 学習データはブラウザ内（localStorage）に保存。Safariのサイトデータを消すと失われるので、設定画面から書き出しておく。
- 合成音声なので、声調や自然さはネイティブ音声に劣る。気になる語はForvoやGoogle翻訳の音声で確認する。
- 音声を別サービスに替える場合は app.js の speak() だけを差し替える。

## 更新の反映
つながっているときは常に最新版を表示し、圏外や通信が遅いとき（4秒超）だけ端末のキャッシュで起動する。新しい版が入ると自動で一度だけ読み込み直す。設定画面の最下部に、端末に入っているバージョン（例：`thai-phrases-v10`）が出る。
